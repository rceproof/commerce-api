# Commerce API

주문·결제·포인트를 처리하는 백엔드 API 서버입니다.
보안 진단 경력을 바탕으로 안전한 트랜잭션 처리(이중 결제 방지, 동시성 제어, 서버 사이드 검증)에 중점을 둡니다.

## 기술 스택

- Node.js

## 실행 방법

​```bash
node server.js
​```

실행 후 브라우저에서 http://localhost:3000 접속
